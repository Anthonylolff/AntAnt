點樣匯出…

iPhone / iPad（RoomPlan，要有 LiDAR：Pro 系列 iPhone 12 起、iPad Pro 2020 起）
  1. 用支援 RoomPlan 匯出 JSON 嘅 App（例如 Apple 嘅 RoomPlan 範例 App，或者其他標明「CapturedRoom JSON」嘅掃描 App）
  2. 逐間房慢慢行一圈，鏡頭對住牆角同門窗
  3. 匯出 .json（唔係 .usdz），AirDrop 去電腦或者直接喺 iPad 開呢頁揀檔
  4. 匯入後去「編輯」逐間房核對：牆厚、門口闊、窗台高
CAD / AutoCAD / 中望 / DraftSight
  1. 另存為 DXF（R12 至 2018 都得）
  2. 牆最好喺 WALL / 牆 圖層；房間用閉合多段線放喺 ROOM 圖層，房名用文字放入房
  3. 門用名有 DOOR／門 嘅圖塊，或者普通門弧都認得
  4. 原本嘅線會變底圖，方便你對住改
Sweet Home 3D
  1. 直接揀 .sh3d 檔（5.3 版或以上存嘅）
  2. 樓層、牆、房、門窗、傢俬都會帶入
Blender / SketchUp / 其他 3D
  1. 匯出 .glb（最好）或者 .obj / .stl
  2. 模型會變半透明參考，同埋由頂影一張底圖畀你用「房間」工具描
Valetudo 掃地機
  1. Valetudo 網頁 → Robot → 地圖 → 匯出 JSON
  2. 每個已分區嘅房間會變成一個長方形房，再對住底圖修正
